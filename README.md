# NOVA Wallet - Digital Wallet QA Portfolio

## Project Overview

NOVA Wallet is a realistic digital wallet / banking web application created as a Software Testing and QA portfolio project.

The application is designed as a demo testing target for practicing functional testing, negative testing, API testing, authorization testing, boundary value analysis, regression testing, and data consistency validation.

The project does not process real money and does not connect to real banking services.
